How Growloop fits together

Sitemap, nine end-to-end flows and the rules that tie OKRs, skills, resources and the board together. Full detail lives in docs/design/ux-flows.md.

Updated Monthly board only · one-click Add to this month

Key decisions

01

One verb: Add

Add puts an item in this month's To Do. Save to library is the someday list. No "Add to backlog" button: Backlog is just a column for committed-but-not-now.

02

Wizard with two engines

The same questions always run. Claude drafts when available; a rules-based starter plan drafts otherwise. Both land on one review screen.

03

Count KRs count by skill

Done items tagged with the skill in that quarter count automatically, so the optional KR link never costs progress. Material KRs are linked by the wizard.

04

Writing has one home

A card's summary and notes are Notebook notes, not copies. Archiving freezes plans and results, never knowledge.

05

Objectives first, softly

Skippable at onboarding; one calm "Set your year" prompt stays where objectives would show. Nothing is locked.

a · updated

First run

Two steps, then the tour. Objectives are asked for, not forced.

  • Name is optional; greeting drops it if blank.
  • Closed midway: resumes at the same step.
  • Hosted demo skips onboarding, loads sample data.

b

OKR wizard

Eight fixed questions (plus one optional for Claude): role, 12-month goal, 2–4 focus skills, level now vs target, weekly time, formats, certification, light quarters.

  • Output: 3–4 objectives per year, one quarter each, 2–3 KRs each with one skill, a type and a target.
  • Claude picks materials from catalog ids only.
  • Material and certification KRs create linked Backlog items.
flowchart TD
  e(["Start wizard"]) --> scope["Scope · default 'Rest of 2026 + 2027'<br/>or '2027 only'"]
  scope --> qs["Questions 1–8, one per screen<br/>'3 of 8' · Back · answers kept if closed"]
  qs --> eng{"Claude available?"}
  eng -->|"yes"| q9["Q9 optional: anything else Claude should know"]
  q9 --> draft["Claude drafts 3–4 objectives × 2–3 KRs<br/>materials chosen from catalog ids only"]
  draft --> ok{"Valid draft?"}
  ok -->|"no / timeout"| retry["'Couldn't draft this time'<br/>Retry · Use starter plan"]
  retry --> rules
  eng -->|"no"| rules["Starter plan from rules<br/>one objective per focus skill, spread over quarters<br/>KRs: top catalog material + count N from weekly time"]
  ok -->|"yes"| rev
  rules --> rev["Review · objectives as cards in quarter lanes<br/>edit title, quarter, KR type, target · add/remove · Start blank"]
  rev --> chk{"Rules met?"}
  chk -->|"no"| fix["Inline error on the card<br/>≤4 objectives per year · 2–3 KRs each<br/>each KR: one skill + target · plannable quarter"] --> rev
  chk -->|"yes"| accept["Accept"]
  accept --> out["Save objectives<br/>material and certification KRs → item in Library + Backlog, linked<br/>count KRs → 'Find resources' on the KR"]
  out --> page["Personal OKRs · year view"]

  • From a KR's "Find resources", Add links to that KR automatically.
  • No objectives yet: toast offers "Set your year".

d · updated

Paste to add

Paste a link or title. Claude fills the details; without it, a pre-filled form.

  • Duplicates caught before any work.
  • Primary: Save and add to this month.
  • Failure never loses the pasted text.

e · updated

Execute the month

The board always opens on the current month. A summary becomes a Notebook entry the moment it's written.

  • Past months: read-only columns, cards still open for notes.
  • Backlog column only on the current month.
  • No future months; Backlog is for later.

  st -->|"backlog or library has items"| pull["'Pick 3–5 for October'<br/>KR-linked backlog items first · or Add from Library"]

  pull --> work["To Do → In Progress<br/>drag, or keyboard 'Move to…' · Backlog for not-this-month"]

  rf -->|"no Claude"| fbh["Setup hint · summary kept as is"]
  sum --> nb["Summary is a Notebook entry, linked to the card<br/>'Summarize in my words' task ticks itself"]
  fb --> nb
  fbh --> nb

Non-blocking banner. Smart defaults make "Confirm all" a single click.

  • Quarter months also close objectives.
  • Missed months: one combined review.
  • Backlog is never reviewed.

KR progress

TypeProgressMet when
MaterialLinked card's task completion, capped at 99 % until DoneCard moves to Done
Certification"Preparing" with task % once the card is on a monthCard Done and "Certification earned" confirmed
CountDone items tagged with the skill, inside the objective's quarter, out of NCount reaches N

Objective progress = mean of its KRs, with a pace label against quarter elapsed. Progress is computed, never typed.

Open questions

Does the rest of 2026 get an objective?Default wizard scope "Rest of 2026 + 2027": at most one objective for Q4 2026, plus 3–4 for 2027. Caps per calendar year.
What about applied-practice KRs ("Interview 12 customers")?Keep three KR types. Practice can be an own library item that counts toward a count KR.
Unfinished objective at quarter end?Close with its score; allow one move to the next quarter in the quarter-month review.
How hard is "objectives first"?Soft gate: skippable, with one persistent "Set your year" prompt.
Adopt the skill-profile extension?Yes to wizard Q4 now; defer the Level chart and CV paste.
