# 001 — Learning-only scope, product people first

**Status:** Accepted · 2026-10-17

## Context
Personal productivity is a crowded space. A generic task manager would compete with Notion, Todoist and Jira on their home turf.

## Decision
The MVP covers **self-development learning only** (no daily tasks) and targets **product people** first. The skill taxonomy and curated library are PM-specific.

## Consequences
- A narrow audience lets the library be genuinely curated and the skill model opinionated.
- The data model keeps skills and materials generic so other roles can be added later without migrations.
